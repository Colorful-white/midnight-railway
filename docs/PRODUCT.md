# 产品与美术约定

核对日期：2026-11-18。以下区分既定方向、当前实现和未来可扩展内容；后续以用户新要求为准。

## 核心体验

这是可以长期增加景观的舒适观景作品。列车在一个微缩星球上行驶，每天按设备本地时间循环；00:00 到达同时作为始发与终点的零点小站。时间不是主视觉，不把页面改造成大时钟或效率工具。

列车应持续有可感知的移动。保留用户认可的正常观景速度与节奏，不增加“加速试乘”。“时段体验”只跳到选定时刻，再以正常时间继续。

景观可以从内部穿过、绕行或盘旋经过，路线与空间关系要可信。后续景观逐个增加，先完成当前小目标，再继续下一项。

## 四季与天气

列车按设备日期运行四天一轮的春、夏、秋、冬。实况在 00:00 换季，当天再次打开仍是同一季节。右上角区段编号旁显示当前季节，「时段体验」选择当季的时刻。

- 春天草色变嫩，低地清晨略有薄雾，约 08:00 的铁路外侧可看到几簇奶黄、蜜桃粉小花。
- 夏天草木更浓，远处更清晰，约 18:00 起的傍晚有一层短暂余晖。
- 秋天原野和矮草转向干草金，林边常青树保留深绿。
- 冬天开阔地有深浅相间的薄雪，南岸原野在约 23:57 偶尔飘几片雪，持续约一分钟。减少动态效果时仍可看到积雪。
- 天色仍遵循原有日内光照。季节色在薄荷海上方减弱，水下保留自己的雾色、地貌及动物。

## 镜头与界面

- **车窗视角**：在车内看窗外，前景和景观符合统一透视与遮挡关系。
- **俯视视角**：能看见列车沿轨道一点点前行，也显示下一站、到达时刻或剩余时间。
- 俯视模式有分段取景、跟随车头、自由镜头。自由模式支持右键拖动、触摸拖动和方向键移动。
- 左上角小星球展示轨道细线和列车位置光点。
- 左下角三横杠菜单集中放置功能；视角切换停靠在菜单按钮上方，避免居中遮挡。
- 当前菜单包括时段体验、镜头选择、添加到主屏幕说明、更新、暂停和全屏。后续功能沿用这一收纳方向。
- 暂停应同时停止列车与装饰动效；遵守系统“减少动态效果”设置。

## 色彩与形体

用户喜欢的七种颜色，及当前鱼体使用的参考值：

| 颜色 | 参考 HEX |
| --- | --- |
| 奶黄 | `#FFE6A3` |
| 蜜桃粉 | `#F3BAC7` |
| 浅薄荷绿 | `#B8DFCA` |
| 天青蓝 | `#AACFE3` |
| 香芋紫 | `#C9B7E1` |
| 奶白色 | `#FFF7E9` |
| 香槟色 | `#EBD8B1` |

这些是受光照影响的三维材质色，不是所有物体都要均匀使用的平面色卡。薄荷、天青作为清透环境色，暖色与香芋紫可用于鱼、珊瑚等点缀，保留留白和前后层次。

花、书、茶、鱼、鳐鱼等已有明确要求：有体积，摆放自然，照顾视角与构图。不要退回到照片、图片平面贴片拼接的做法。允许用几何和程序化材质表达细节。

## 薄荷海当前内容

透明水下长廊、珊瑚花园绕行、出海坡道，配合柔和的夜间水下照明。车窗和俯视观看同一个场景。

- 薄荷海共 **147 条鱼**。126 条分布在 9 个位置，各有前后两层；环线中段三个车窗空窗各补一组 7 条远景鱼。每个小群包含全部七色。
- 鱼会游动、转向、摆尾，有远近距离和遮挡。
- 奶白色鳐鱼有立体胸鳍、头部、眼睛、腹部细节和渐细长尾；游动包含鳍面起伏与轻微侧倾。
- 有水母、气泡、柔和光束和海底变化的光斑。
- 两处曾出现的折返急拐已重画为相切进出弯；环线与上层出场线路需要保持净空。

## 眠云谷

薄荷海正式观景段在 22:48 结束，列车五分钟后于 22:53 进入眠云谷，到 23:00 接入月下归途。入谷有零星暖灯和小片杉林。约 22:56 进入谷心，两侧山壁高耸，谷底积着缓慢流动的云雾，睡鹿藏在山脊轮廓里，坡肩上的守梦小屋亮着窗。尾段留着深蓝远山、散开的薄云和小月亮。

眠云谷沿用原来的铁路、时刻插值和速度。入谷与出谷以地形、能见度和暗处留白渐变。俯视的分段取景在谷内展开到远一些，车窗保留日常前景。暂停时云随其他动效停止，减少动态效果时云保留静态形状。

## 车窗前景与封面

- 窗边左侧是香芋紫风铃花；有花筒、五瓣花口、内壁、花萼、花蕊、花苞和叶脉。
- 右侧摆合着的绿色书、茶碟和热茶；不能漂浮或与窗台透视冲突。
- 热气缓慢上升、摆动、变淡，边缘柔和，暂停时一起停止。
- 启动封面文字为 **「泉儿和果儿的开心小天地」**。这是封面标题，不等于要同步改应用名称。
- 封面有小星球与列车、进度条；等待首帧准备好再淡入。通常约两秒，加载慢时等待更久。
- 新页面会显示封面；已安装应用从后台回到前台也会显示。当前不能精确区分点击桌面图标和普通应用切换。
- 桌面图标沿用封面的星球列车，使用 `icons/journey-*.png`。

## 访问和长期方向

面向朋友的私人定制版，已确定使用可公开访问的固定链接，兼顾苹果与安卓。当前交付是 PWA；没有正在维护的原生 APK 或 iOS 工程。

长期目标是逐步增加独特景观、提升模型和光影细节，同时保持舒适、整洁、手机可用。景观注册框架、持久化回归测试等属于维护方向，尚未自动完成，见 [代码结构](ARCHITECTURE.md)。
